# 🎬 Movie Ticket Booking System

A full-stack Movie Ticket Booking web application built using the MERN stack. Users can register, login, browse movies, select seats, book tickets, and view their booking history.

## 🚀 Live Demo

[Movie Ticket Booking Website](https://movie-ticket-booking-frontend-099k.onrender.com)

## 📌 Features

- User Registration & Login
- Browse Available Movies
- View Movie Details
- Interactive Seat Selection
- Online Ticket Booking
- Booking Confirmation
- My Bookings Section
- JWT-based Authentication
- MongoDB Database
- REST API Integration

## 🛠️ Tech Stack

### Frontend
- React.js

- JavaScript
- Axios
- React Router
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
